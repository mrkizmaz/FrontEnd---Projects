# Note Map
- Harita alani icin kütüphane kullanmamiz gerekecek;
    1. google maps api
    2. harita icin cok tercih edilen kütüphane: leaflet -> mekan göstermek icin kullanilmaz

- Sidebar acilir kapanir yapida olmasi gerekli

## Kullanici Karsilama
1. Kullanicidan konumunu bizimle paylasmasini isteyecegiz
2. Izin verirse haritanin merkezini ona göre ayarlayacagiz ve mevcut konumunu haritada imlec olarak gösterecegiz
3. Izin vermezse varsayilan olarak Ankarayi merkez olarak belirleyecegiz


## Yeni Not Olusturma Senaryosu
1. Kullanici haritada bir yere tiklar
2. Ekranda bir form alani acilir
3. Form alanina gerekli bilgiler girilir
4. Form kapatilir ve not bilgileri localstorage'a kaydedilir

## Not Card Islemleri
1. Silme butonu ile not silinebilmeli
2. Ucak butonu ile haritada notun konumu gösterilmeli
